    Protocol detail

    How the value is priced

    We look at the 128 protocols in the snapshot that already trade, and for each one divide its market cap by its TVL. The middle value — $0.21 per $1 of TVL — is the base price. Big protocols get a smaller price per dollar (the size fit says value grows slower than TVL, slope 0.52), and each category gets a ridge effect: its average log miss against the base price, shrunk toward no effect by 16 pseudo-observations, so a thin category barely moves the price. A fast-growing week, a long wait with no token and running on more chains were all tried the same way — none of them lowered the held-out miss in both tests, so they are not in the price. They do feed the token odds instead. The formula is:

    implied value = TVL × base price × size factor × category effect × token odds

    Fit: 128 trading protocols, log-log slope 0.52, R² 0.19, base price $0.21 per $1 of TVL.
